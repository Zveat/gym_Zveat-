# Personal Gym OS — инструкция

Всё, что нужно сделать один раз, и как этим пользоваться в зале.

Приложение уже выложено: **https://gym-zveat.vercel.app**

Прямо сейчас оно работает без аккаунта — данные лежат на телефоне. Часть 1
подключает базу, чтобы история жила на сервере и была видна с любого
устройства. Всё, что успеете натренировать до этого, переедет в аккаунт само.

---

## Часть 1. База данных (один раз, ~5 минут)

Проект в Firebase: отображаемое имя `gym-zveat`, внутренний ID
`titovstroy-dev` (ID неизменяемый, поэтому ссылки ниже с ним — это нормально).

### 1.1. Создать базу

Открыть: https://console.firebase.google.com/project/titovstroy-dev/firestore

1. **Standard edition** → **Next**
2. Database ID: оставить `(default)`
   Location: **`europe-west3`** → **Next**
   *Регион потом не меняется.*
3. **Production mode** (не Test mode) → **Create**
4. Подождать ~30 секунд

### 1.2. Включить вход по почте

Открыть: https://console.firebase.google.com/project/titovstroy-dev/authentication/providers

1. Если просит — **Get started**
2. Строка **Email/Password** → нажать
3. Первый тумблер **Enable** → **Save**
   *Второй (Email link / passwordless) включать не надо.*

### 1.3. Забрать конфиг

Открыть: https://console.firebase.google.com/project/titovstroy-dev/settings/general

1. Пролистать вниз до **Your apps**
2. Нажать значок **`</>`**
3. App nickname: `gym-os`
   **«Also set up Firebase Hosting» — НЕ ставить**
4. **Register app**
5. Появится блок `const firebaseConfig = { ... }` — скопировать целиком

Эти шесть значений публичные по своей природе: они попадают в бандл
приложения и лишь указывают на проект. Доступ решают правила Firestore и
пароль от аккаунта.

### 1.4. Отдать конфиг

Прислать блок в чат — дальше всё на мне: переменные в Vercel, пересборка,
правила доступа.

Если делаете сами: Vercel → проект `gym-zveat` → **Settings → Environment
Variables** → шесть переменных, затем **Deployments → … → Redeploy**
(обязательно: значения вшиваются при сборке).

| Переменная | Что вставить из `firebaseConfig` |
|---|---|
| `NEXT_PUBLIC_FIREBASE_API_KEY` | `apiKey` |
| `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN` | `authDomain` |
| `NEXT_PUBLIC_FIREBASE_PROJECT_ID` | `projectId` |
| `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET` | `storageBucket` |
| `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID` | `messagingSenderId` |
| `NEXT_PUBLIC_FIREBASE_APP_ID` | `appId` |

Правила доступа лежат в `firebase/firestore.rules` — каждый пользователь
видит только своё дерево `users/{uid}`. Применяются командой
`firebase deploy --only firestore:rules` либо копированием в консоль:
Firestore → **Rules** → вставить → **Publish**.

## Часть 2. Поставить на iPhone (один раз, минута)

1. Открыть **https://gym-zveat.vercel.app** в **Safari** (именно в Safari, не в
   Chrome — иначе не поставится на экран)
2. **Поделиться** → **На экран «Домой»** → **Добавить**
3. Дальше запускать только с иконки

Это не только удобство: приложения с домашнего экрана Safari не подчищает,
а обычные сайты — может. Плюс запускается без адресной строки, во весь экран.

## Часть 3. Как пользоваться в зале

### Тренировка

1. **START WORKOUT** на главном экране
2. Выбрать день (предлагается тот, который дольше всех не тренировали) и
   режим:
   - **NORMAL** — программа как написана
   - **LIGHT** — вес −15%, на подход меньше, без отказных
   - **HEAVY** — вес +5%, диапазон повторений ниже
   - **RECOVERY** — вес −30%, примерно половина подходов
   Под режимом сразу видно, что именно изменится: `50 kg × 12 × 4` →
   `42.5 kg × 12 × 3`. Режимы не создают отдельных программ.
3. **START WORKOUT** → открывается список упражнений, текущее помечено
4. Нажать упражнение. На экране:
   - план подхода
   - **LAST TIME** — что делали в прошлый раз
   - **PERSONAL BEST** — рекорд
   - крупные **вес** и **повторения** с кнопками −/+
   - насколько тяжело: EASY / GOOD / HARD / FAILURE (необязательно)
5. **COMPLETE SET** → подход сохранён, запустился таймер отдыха
6. После отдыха — следующий подход. Всё то же.
7. Когда упражнение закрыто — **ДАЛЕЕ**, к следующему
8. **ЗАВЕРШИТЬ ТРЕНИРОВКУ** → экран разбора: где можно прибавить вес, где
   держать, где снизить. **ACCEPT** меняет план на будущее, история остаётся
   как есть.

Телефон можно блокировать и убирать в карман: таймер и тренировка не
сбиваются, перезагрузка тоже ничего не теряет.

### Мелочи, которые пригодятся

- **Точный вес** — нажать на само число, откроется клавиатура
- **Шаг ±** — переключается тут же: 1 / 2.5 / 5 кг
- **Лишний подход** — «+ подход» в списке
- **Пропустить упражнение** — кнопка внизу экрана упражнения
- **Заметка на эту тренировку** — «ЗАМЕТКА К УПРАЖНЕНИЮ»
- **Быстрая отметка** — «Слишком легко», «Боль», «Плохая техника» и т.п.
  Отметка «Боль» перебивает арифметику: прибавить вес приложение не
  предложит, даже если план закрыт
- **Техника, история, графики** — кнопка **ИНФО** справа сверху

### Заметки, которые должны быть всегда на виду

ИНФО → **Заметки** → тип **Важная**. Такая заметка висит прямо на экране
упражнения — например «не увеличивать вес, пока не 12 во всех подходах».

## Часть 4. Внести прошлые тренировки

Два способа.

**По одной** — **История** → **+ ВНЕСТИ**: дата, день программы, план
подставится сам, останется поправить цифры.

**Массово** — **Ещё → Импорт истории**:
- вставить старые заметки текстом
- или выбрать файл: **CSV, XLSX, TXT**

Разбор понимает даты (`01.08.2026`, `2026-08-01`, `14 сентября`, `SEP 14`) и
подходы (`50 x 12`, `52,5кг × 10`, `22.5 x 12 x 4`, `50кг 3 по 12`,
`последний 60кг`). Ничего не сохраняется, пока вы не подтвердите
предпросмотр: там видно, что приложение угадало, и это можно поправить.

## Часть 5. Если что-то не так

**Не открывается / белый экран** — обновить страницу. Приложение статическое,
падать там нечему; чаще всего это кэш старой сборки.

**Не вижу тренировку на другом устройстве** — проверить, что на обоих вошли в
один аккаунт: **Ещё → Настройки → Аккаунт**.

**Нет интернета в зале** — так и должно работать. Подходы пишутся, уйдут на
сервер сами при появлении связи.

**Резервная копия** — **Ещё → Настройки → Данные → Сохранить резервную
копию**. Файл JSON со всем: программы, история, заметки, фото. Восстановление
рядом.

**Сбросить всё** — там же. Удалит и на сервере, вернёт предустановленную
программу. Отменить нельзя.
