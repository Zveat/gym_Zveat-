# Сверка с ТЗ

По разделам ТЗ: что сделано, где это в приложении, что можно проверить самому.

Обозначения: **✅** сделано · **⚠️** сделано частично · **❌** не сделано ·
**↔️** сделано иначе, чем в ТЗ

---

## Продукт и проблема (§1–4)

| § | Требование | | Где проверить |
|---|---|---|---|
| 1 | Не список упражнений, а система: программы, ведение тренировки, история, прогрессия, заметки, техника, режимы | ✅ | всё приложение |
| 3.1 | История не теряется при изменении веса | ✅ | измените вес в программе → История прошлых тренировок не изменилась |
| 3.2 | Видно прогрессию: как менялся вес, повторения, где застой | ✅ | Прогресс → Прогресс по упражнениям |
| 3.3 | Заметки не превращают программу в текст | ✅ | заметки отдельной сущностью: ИНФО → Заметки |
| 3.4 | Техника отдельно от весов | ✅ | ИНФО → Техника |
| 3.5 | Режимы нагрузки без копирования программы | ✅ | экран запуска → Легкая / Тяжелая / Восстановление |
| 3.6 | История тренировок | ✅ | История (список и календарь) |
| 3.7 | Аналитика: мышцы, веса, объём, количество | ✅ | Прогресс |
| 4 | **Программа ≠ история** | ✅ | ключевое правило, см. ниже |

**Как проверить главное правило.** Проведите тренировку, сделав не по плану
(например 55 вместо 50). Затем: История → тренировка покажет 55; Программы →
в программе осталось 50. Программа меняется только через «Что дальше с
весами» → ПРИНЯТЬ.

заполняются с первой тренировки.

## Приоритеты (§52)

**Приоритет 1** — всё: программы, дни, упражнения, проведение тренировки,
подходы, вес и повторения, история, история упражнения, графики, заметки,
таймер отдыха, предустановленная программа. ✅

**Приоритет 2** — всё: три режима, рекомендации прогрессии, рекорды,
аналитика по мышцам, вес тела. ✅

**Приоритет 3** — боль ✅, массовый импорт ✅, AI-разбор ❌ («в будущем»),
умные рекомендации ⚠️ (движок прогрессии есть, «умного» слоя сверх него нет),
расширенная аналитика ⚠️ (объём, мышцы, динамика, рекорды есть; схемы тела
нет).

## Что проверяется само

- `npm test` — 94 теста на логику: разбор заметок и Excel, режимы, прогрессия,
  рекорды, аналитика, предустановленная программа
- `npm run test:e2e` — 106 проверок в реальном браузере на двух размерах
  iPhone: тренировка целиком, перезагрузка посреди неё, работа офлайн, импорт,
  фото, отсутствие горизонтальной прокрутки, отсутствие английских слов
- `npm run typecheck` — strict, включая неиспользуемые переменные
